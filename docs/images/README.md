## Tips

- **Take screenshots in light mode** for the hero/README (higher contrast in thumbnails); a dark-mode shot or two is a nice bonus.
- Keep them **PNG**, cropped to the app window, ideally 16:9.
- A short **GIF** of the deduction loop (examine → question → contradict → deduce) makes a great addition to the README if you want one; name it `demo.gif`.
- If you add or rename images, update the references in `README.md` and the files under `docs/`.
